# Документация сервиса (wiki)

Здесь лежат тексты wiki и инструменты, которые приводят её в порядок. Wiki развёрнута на том же сервере, что и приложение: **https://tellscope40.headsmade.com:8445** (Wiki.js в контейнере `wiki`, база `wikijs_datadb`, порт nginx `8445`).

## Состав

| Файл | Что это |
|---|---|
| `pages/*.md` | Тексты страниц в markdown — по одной на каждый раздел сервиса |
| `manifest.json` | Заголовки, описания, локаль и место страницы в навигации на главной |
| `wiki_sync.py` | Синхронизация: создаёт новые страницы, обновляет изменённые, пересобирает навигацию на Home |
| `wiki_labels.py` | Выгружает подписи интерфейса из исходников фронтенда в `labels.txt` — чтобы тексты совпадали с тем, что видно на экране |
| `deploy_frontend.sh` | Выкладка фронтенда вместе с обновлением документации |
| `wiki_locale.py` | Установка локали, перенос страниц между локалями и выбор основной (нужен редко) |

## Как это работает на сервере

Тексты для публикации живут в `/opt/tellscope-wiki/pages/`, рядом — `manifest.json`; инструменты лежат там же. Этот репозиторий — источник правды: после правки файлов здесь их нужно перенести на сервер и запустить синхронизацию (или просто запустить `deploy_frontend.sh`, он делает и то, и другое).

```bash
# на сервере, от root
BE=/home/dev/tellscope_app/tellscope_backend
PY=$BE/venv_py312_clean/bin/python
cp $BE/docs/wiki/pages/*.md /opt/tellscope-wiki/pages/
cp $BE/docs/wiki/manifest.json /opt/tellscope-wiki/
$PY /opt/tellscope-wiki/wiki_sync.py --dry-run    # посмотреть, что изменится
$PY /opt/tellscope-wiki/wiki_sync.py              # применить (и обновить навигацию)
```

## Выкладка фронтенда вместе с документацией

```bash
sudo bash /opt/tellscope-deploy/deploy_frontend.sh
```

Скрипт собирает фронтенд, публикует сборку, перезапускает nginx, обновляет подписи интерфейса в `labels.txt` и синхронизирует страницы wiki. Если тексты не менялись, синхронизация ничего не делает — она идемпотентна.

## Доступ

Синхронизация входит в wiki служебной учётной записью `wiki-sync@tellscope.local` (группа администраторов). Логин и пароль лежат в `/root/.tellscope/wiki-sync.json` (права 600) — читать может только root и только он же запускает синхронизацию. Учётную запись можно удалить: тогда публикация вернётся к ручному режиму.

## Правила оформления страниц

* Заголовки разделов — с эмодзи, как на главной странице wiki.
* Каждая страница отвечает на пять вопросов: зачем раздел, как пользоваться (по шагам), как читать цифры, типовые задачи, ограничения.
* Формулировки совпадают с интерфейсом — их источник `wiki_labels.py`.
* В конце — ссылки на связанные разделы.
* Первый заголовок (`# ...`) в файле не нужен: заголовок страницы берётся из `manifest.json`, чтобы не дублироваться в wiki.
