# Документация сервиса (wiki)

Здесь лежат тексты wiki и инструменты, которые приводят её в порядок. Wiki развёрнута на том же сервере, что и приложение: **https://tellscope40.headsmade.com:8445** (Wiki.js в контейнере `wiki`, база `wikijs_datadb`, порт nginx `8445`).

Страницы хранятся в локали **`ru`** — это основная локаль wiki, поэтому адреса идут без префикса: `/nabory-dannyh`, `/otchety`. Русская локаль установлена полностью, интерфейс wiki тоже можно переключить на русский в профиле.

## Состав

| Файл | Что это |
|---|---|
| `pages/*.md` | Тексты страниц в markdown — по одной на каждый раздел сервиса |
| `manifest.json` | Заголовки, описания, локаль и группировка страниц в навигации на главной |
| `wiki_sync.py` | Синхронизация: создаёт новые страницы, обновляет изменённые, пересобирает навигацию на Home |
| `wiki_labels.py` | Выгружает подписи интерфейса из исходников фронтенда в `labels.txt` — чтобы тексты совпадали с тем, что видно на экране |
| `wiki_locale.py` | Работа с локалями wiki: `--list`, `--install ru`, `--migrate en ru`, `--default ru` |
| `deploy_frontend.sh` | Выкладка фронтенда вместе с обновлением документации |

## Как обновить документацию

Основной путь — правка файлов в этом каталоге и обычная выкладка:

```bash
sudo bash /opt/tellscope-deploy/deploy_frontend.sh
```

Скрипт собирает фронтенд, публикует сборку, перезапускает nginx, копирует страницы из `docs/wiki` в рабочую папку `/opt/tellscope-wiki`, обновляет подписи интерфейса и синхронизирует wiki. Если тексты не менялись, wiki не трогается — синхронизация идемпотентна.

Если нужно обновить только документацию, без сборки фронтенда:

```bash
BE=/home/dev/tellscope_app/tellscope_backend
PY=$BE/venv_py312_clean/bin/python
cp -r $BE/docs/wiki/pages/. /opt/tellscope-wiki/pages/
cp $BE/docs/wiki/manifest.json /opt/tellscope-wiki/manifest.json
$PY /opt/tellscope-wiki/wiki_sync.py --dry-run    # посмотреть, что изменится
$PY /opt/tellscope-wiki/wiki_sync.py              # применить (и обновить навигацию)
```

Точечно одна страница: `wiki_sync.py --only otchety`. Пересобрать только навигацию на главной: `wiki_sync.py --home-nav`.

## Доступ

Синхронизация входит в wiki служебной учётной записью `wiki-sync@tellscope.local` (группа администраторов). Логин и пароль лежат в `/root/.tellscope/wiki-sync.json` (права 600) — читать может только root, и только root запускает синхронизацию. Учётную запись можно удалить в разделе «Пользователи и доступ»: тогда публикация вернётся к ручному режиму.

## Правила оформления страниц

* Каждая страница отвечает на пять вопросов: зачем раздел, как пользоваться (по шагам), как читать цифры, типовые задачи, ограничения.
* Формулировки совпадают с интерфейсом — источник подписей `wiki_labels.py`.
* Заголовки разделов — с эмодзи, как на главной странице wiki.
* В конце — ссылки на связанные разделы.
* Первый заголовок (`# ...`) в файле не нужен: заголовок страницы берётся из `manifest.json`, чтобы не дублироваться в wiki.
* Навигация на главной странице собирается между маркерами `<!-- nav:start -->` и `<!-- nav:end -->` и пересобирается автоматически.
