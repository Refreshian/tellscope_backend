Раздел показывает **как расходится информация**: от первых публикаций до пиков активности, какие площадки и авторы запускают тему, а какие её подхватывают.

## Как пользоваться

1. Выберите **тему** и **период**.
2. Уточните фильтры: площадки, тип сообщений, авторы.
3. Нажмите **«Запуск»** и дождитесь расчёта — для больших тем он идёт дольше.
4. Изучите блоки: тепловая карта «тема × месяц», динамика объёма, тональность по площадкам, авторы, инфоповоды.
5. Кнопка **«Обновить данные»** пересчитывает выборку, если вы поменяли фильтры.

## Что показывает

* **Динамику**: в какие месяцы тема звучала громче всего и за счёт чего.
* **Источники**: какие площадки дали первые сообщения, а какие — основной объём.
* **Авторов**: кто чаще всего пишет по теме и на каких площадках.
* **Тональность по площадкам**: где разговор злее, а где спокойнее.

## Встроенный ИИ-анализ

Внизу страницы есть поле для вопроса по текущей выборке. Готовые вопросы подсказывают, что спросить, например:

* какие источники дают больше всего негатива при текущем срезе;
* как тип сообщения связан с тональностью;
* какой путь от запроса к источнику самый объёмный.

Ответ строится только по отфильтрованным данным — то есть по тому, что вы видите на экране.

## Нюансы

* Темы приходят из разметки источника: если сообщение не отмечено темой, оно не попадёт в выборку темы (но попадёт в общую аналитику по словам).
* Если данных нет, интерфейс прямо скажет: «Нет отфильтрованных данных для анализа» — снимите лишние фильтры.
* Для больших наборов расчёт может занимать минуты: страница не «зависла», идёт агрегация по всем сообщениям.
