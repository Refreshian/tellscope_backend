Раздел для **создания своих инструментов**: сохранённые цепочки шагов, набор инструментов, модель и расписание. Отчёты складываются в папку агента.

## Что можно настроить

* **Цепочку шагов** — что агент делает по порядку: какие данные берёт, что считает, что собирает на выходе.
* **Набор инструментов** — какие возможности сервиса доступны агенту.
* **Модель** — какую модель использовать для рассуждений и формулировок.
* **Расписание** — запускать вручную или регулярно.

## Готовые сценарии

В разделе есть готовые варианты задач, которые можно взять за основу:

* **Подробный разбор темы** — что происходит в теме и из чего складывается картина;
* **Сводный отчёт по бренду** — общий документ по бренду за период;
* **Негатив и жалобы** — концентрация негатива и его причины;
* **Сравнить периоды** — что изменилось между двумя отрезками времени.

## Как пользоваться

1. Опишите задачу для агента.
2. Выберите инструменты и модель.
3. Запустите: статус виден в интерфейсе — «В очереди», «Работает», «Готово», «Ошибка».
4. Результат забирайте из папки агента в Наборах данных.

## Нюансы

* Если список инструментов не загрузился — обновите страницу: это сетевая ошибка, а не потеря настроек.
* Регулярные запуски занимают ресурсы: расписание лучше ставить на ночные часы.
