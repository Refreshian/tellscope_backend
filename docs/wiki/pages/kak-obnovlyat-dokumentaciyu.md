Страницы этой wiki живут в файлах и синхронизируются с wiki одним скриптом. Когда интерфейс меняется, достаточно поправить файлы — и запустить синхронизацию: изменённые страницы обновятся, новые создадутся, остальные останутся как были.

## Где что лежит

| Что | Где |
|---|---|
| Тексты страниц (markdown) | `/opt/tellscope-wiki/pages/` |
| Заголовки и описания страниц | `/opt/tellscope-wiki/manifest.json` |
| Служебный доступ к wiki | `/root/.tellscope/wiki-sync.json` (только для root) |
| Подписи интерфейса из кода | `/opt/tellscope-wiki/labels.txt` |

## Как обновить страницы

1. Поправьте нужный файл в `/opt/tellscope-wiki/pages/` (это обычный markdown).
2. Посмотрите, что изменится, без публикации:

```bash
sudo /home/dev/tellscope_app/tellscope_backend/venv_py312_clean/bin/python \
     /opt/tellscope-wiki/wiki_sync.py --dry-run
```

3. Примените изменения (и обновите навигацию на главной странице):

```bash
sudo /home/dev/tellscope_app/tellscope_backend/venv_py312_clean/bin/python \
     /opt/tellscope-wiki/wiki_sync.py
```

4. Нужна одна страница — добавьте путь:

```bash
... wiki_sync.py --only nabory-dannyh
```

## Как понять, что изменилось в интерфейсе

Подписи на экранах берутся прямо из исходников приложения. Скрипт выгружает их в файл:

```bash
sudo /home/dev/tellscope_app/tellscope_backend/venv_py312_clean/bin/python \
     /opt/tellscope-wiki/wiki_labels.py
```

Откройте `/opt/tellscope-wiki/labels.txt` и сверьте с текстом страницы: если подпись кнопки или раздела изменилась — поправьте формулировку в файле страницы.

## Правила, по которым написаны страницы

* Заголовки разделов — с эмодзи, как на главной странице wiki.
* Каждая страница отвечает на пять вопросов: зачем раздел, как пользоваться (по шагам), как читать цифры, типовые задачи, ограничения и нюансы.
* Формулировки совпадают с интерфейсом: если на кнопке написано «Проверить N сообщ.», в тексте тоже так.
* В конце страницы — ссылки на связанные разделы, чтобы можно было перейти по цепочке.

## Что делать при сбое

* **«не удалось войти»** — проверьте, что служебная учётная запись `wiki-sync@tellscope.local` активна и входит в группу администраторов.
* **«ОШИБКИ: …»** — в выводе будет указана страница и сообщение wiki; чаще всего это конфликт пути (страница с таким путём уже создана вручную).
* **Навигация на главной не обновилась** — запустите отдельно: `wiki_sync.py --home-nav`.
* **Служебный доступ нужно отключить** — удалите пользователя `wiki-sync@tellscope.local` в разделе «Пользователи и доступ»; синхронизация после этого работать не будет до создания нового доступа.
