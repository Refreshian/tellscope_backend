# Мосинформ.Рейтинг

Ежемесячный контур: пачка выгрузок → полки в Excel → презентация в каркасе пилота (слайды 16–31).

## Что на входе

- Word Медиалогии с полными текстами (как в `002 Июль.zip` — единый поиск по ОИВ).
- Опционально Excel Медиалогии со сводом: сообщения, главная роль, МедиаИндекс, охват, тон.
- Опционально панели СКАН — пока кладём в заметки, в рейтинг не вмешиваем.

## Запуск

```powershell
pip install -e .
python -m mosinform run _inbox\july_clean -o output\july --period "Июль 2026"
```

Пилотная неделя:

```powershell
python -m mosinform run _inbox\pilot_clean -o output\pilot --period "1–7 июля 2026"
```

Tellscope (Qwen на вашей стороне) включается флагом `--tellscope` и полями в `config/settings.yaml`. Без него работает словарь ОИВ + эвристика: объект, спикер, грубая роль, признаки релиза.

## Выход

- `mosinform_rating.xlsx` — messages / objects / media / speakers / daily.
- `mosinform_rating.pptx` — 15 слайдов: покрытие, объём, спикеры, охват, СМИ, тон, роль, концентрация, пересечения, инициированные, динамика, МедиаИндекс, три вывода.

Охват и МедиаИндекс появляются только если в папке есть Excel-свод Медиалогии. В чистом Word их нет — слайды это прямо говорят.

## Настройка

- `config/objects.yaml` — департаменты, проекты, алиасы, руководители.
- `config/media.yaml` — канонические СМИ и контур (official / independent).
- `config/settings.yaml` — URL Tellscope, top-N на слайдах.
